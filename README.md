# 🌤️ Real-Time Weather

## 📌 Description

This project is a web application designed to provide **real-time weather observations** based on the **user’s location**.

The goal is to deliver up-to-date weather information in a simple, fast, and user-friendly way.

## 🚀 Features

* User location detection
* Real-time weather display
* Information such as temperature, weather conditions, humidity, etc.
* Responsive and intuitive interface

## 🛠️ Technologies Used

* HTML
* Bootstrap
* JavaScript
* External weather API

## 🌍 Usage

The application retrieves the user’s location (with permission) and requests data from an external weather API to display current weather information on the screen.

## 📎 Notes

This project is under development and may continue to evolve with new features and interface improvements.
